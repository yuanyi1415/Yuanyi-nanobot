## 功能需求

**FR-1（切片 1）观测事件**：普通消息进入 build 前记录——消息摘要（截断 200 字）、判定车道（fast/skill/other）、skill 候选召回数/候选名/是否绑定/绑定原因。写结构化日志（loguru，channel=observability），不落会话历史。flag `experimental.observe_lane` 默认 false。

**FR-2（切片 2）SkillDescriptor**：SkillsLoader 生成只读 descriptor `{name, source, description, availability, activation(auto/manual/always/disabled), tags, triggers, content_fingerprint}`；无新字段的旧 skill 一律 `activation=auto`；`disabled/manual/always` 语义保留。

**FR-3（切片 2）本地确定性召回**：对 user 消息做词项匹配（消息文本 vs 候选 skill 的 name/description/tags/triggers）；高置信单一候选→绑定；无候选→不绑定；近似多候选→**V1 不绑定**（不引入 LLM 选择器，只记录观测）。预算：最多绑定 N 个（配置初始 2）、正文 token 上限（配置初始 2000）。

**FR-4（切片 2）注入**：`_build_initial_messages` 调用 `build_messages` 时传入绑定 skill 名。合并规则：`$skill` 显式 > 自动绑定（自动绑定追加到 active_skill_names 尾部）；always 语义不变（build_system_prompt 内部处理）。flag `experimental.skill_auto_bind` 默认 false。

**FR-5（flag 关闭零影响）**：两个 flag 默认 false；关闭时零新增模型调用、零观测日志、零注入、现有测试全绿。
