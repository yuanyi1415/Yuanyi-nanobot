# V1 实施前回放用例

**状态：** 开发前门禁
**日期：** 2026-08-10
**关联：** AC-001 至 AC-016；ADR-008；[执行图最小桥接方案](../03_方案/执行图最小桥接方案.md)

本文件是切片 A-D 的行为验收源。每条用例同时断言用户可见结果、工具/subagent 事件、Session/provider/memory 写入与消息路由；不能只断言“有返回”。

| ID | 场景输入与前置 | 必须验证 |
| --- | --- | --- |
| EV-001 | 没有任务、附件、回复或任务图；用户说“帮我处理一下”。 | 仅一个澄清问题；零业务工具、零 Planner、零 subagent、零 memory consolidation。 |
| EV-002 | 没有任务；用户问可由当前消息直接回答的闲聊/定义问题。 | 无工具 `reply`；用户消息与答复被保存；无 provider state 写入。 |
| EV-003 | 有唯一 TaskFrame；用户说“继续”。 | 产生 `ready`，进入原有权限/工具路径；不因动作类型重复确认。 |
| EV-004 | 有两个无关活动任务；用户说“继续”。 | 仅询问推进哪一个；不按最近任务猜测。 |
| EV-005 | 已确认任务图有两个关系明确的 ready 只读节点，容量足够。 | 计划含两个可并行子节点；各节点有输入、交付物、验收与互斥写入范围。 |
| EV-006 | 两节点存在依赖或共享写入目标。 | 计划串行；第二节点绝不在前置成功前启动。 |
| EV-007 | Planner 输出非法 schema 或循环依赖。 | 仅降级为一个 parent 节点；不自由 spawn。 |
| EV-008 | 计划 A 正在运行，计划 B 的同会话结果先到。 | B 结果不进入 A queue/历史/模型；只进入 B 的 deferred 证据。 |
| EV-009 | 有效 session A、B 不同；A 的结果到达时 B 正在运行或空闲。 | B 的 queue、历史、模型请求和 outbound 均不含 A 结果。 |
| EV-010 | 公告发布与 subagent cleanup 并发；随后重复公告相同 task。 | `spawn_planned` 已在启动临界区写入 route receipt；第一次依收据消费一次；第二次隔离；无双重模型回注。 |
| EV-011 | 主子并行，主 agent 在子节点未结束时生成“完成”文本并流式输出。 | 该文本不对用户提交；子节点汇合后才生成/提交整合终答。 |
| EV-012 | 子节点失败、取消、超时、Runner 达迭代上限。 | 最终文本说明未完成事实；不标记 TaskFrame completed。 |
| EV-013 | 规划时有容量，但 spawn 前被其他会话占满。 | 节点一次安全父回退或 `blocked`；无重复 spawn 风暴。 |
| EV-014 | 用户停止、修改目标、进程中断后再“继续”。 | 旧 plan 终结；新 plan id 生成；旧未消费结果不能满足新 plan。 |
| EV-015 | metadata 损坏、版本未知或超过上限。 | 不读取猜测状态；只安全澄清；旧 Session 其他数据不被改写。 |
| EV-016 | feature flag 关闭，覆盖普通消息、命令、内部消息、/goal、memory、subagent 与 WebUI。 | 新模块调用/metadata 写入/额外模型调用均为零；既有回归行为不变。 |

## 通过条件

- EV-001 至 EV-016 全部有自动化或可复现的集成回放；
- EV-008 至 EV-014 必须验证事件序列，而非仅断言最终文本；
- 开关关闭回归与计划模式回归分别运行；
- 任一跨 session、跨 plan、重复消费或伪终答失败均阻止进入灰度。
