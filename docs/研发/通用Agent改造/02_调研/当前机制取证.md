# 当前机制取证：nanobot 的任务理解与 subagent

**取证日期：** 2026-08-09  
**范围：** 当前工作区源码及现有架构图；不包含运行实例探针  
**结论状态：** 已核对源码；后续实现前需随基线提交再次复核

## 1. 取证结论

nanobot 当前并不存在独立的自然语言“意图识别”或“任务规划”模块。普通消息的理解是隐式完成的：系统先将会话、记忆、提示词、技能、工具和运行时信息拼入一次主模型请求，再由主模型决定直接回答或调用工具。

这意味着当前系统没有保存本轮任务对象、目标、授权、歧义或委派理由的结构化结果，也没有在工具调用之前验证对象是否存在。

## 2. 当前时序

```text
InboundMessage
  → AgentLoop.restore
  → AgentLoop.compact
  → AgentLoop.command
  → AgentLoop.build
  → AgentLoop.run
  → AgentRunner：LLM 请求 ↔ 工具调用循环
```

来源：`nanobot/agent/loop.py` 的 `_process_message`。

### 已有确定性边界

- `nanobot/command/router.py`：斜杠命令由优先、精确、前缀三级路由处理；非法斜杠命令不会进入 LLM；
- `nanobot/command/builtin.py`：`/goal <task>` 显式标记长期目标请求；
- `nanobot/session/goal_state.py`：仅保存显式长期目标状态；
- `nanobot/session/turn_continuation.py`：仅在活动长期目标达到工具迭代边界时，创建内部续办切片。

这些是控制/续办机制，不是普通自然语言的对象锚定机制。

## 3. 当前上下文如何影响模型理解

`nanobot/agent/context.py` 的 `ContextBuilder` 会为普通用户消息拼装：

- 身份、运行环境与渠道策略；
- 项目 `AGENTS.md`，以及 agent 工作区的 `SOUL.md`、`USER.md`；
- `tool_contract.md`；
- 长期记忆、近期历史、会话压缩摘要；
- 显式 `$skill` 与常驻技能；
- 当前消息、附件和运行时上下文块。

`AgentLoop._build_turn` 从会话读取回放历史，解析当前消息的运行时上下文，并构造上述完整提示。当前没有独立字段保存“此消息指向哪个对象”。

## 4. 当前执行与委派机制

`nanobot/agent/runner.py` 将完整上下文和工具定义提交给 provider；只有模型返回 tool call 后，Runner 才执行工具。工具批处理的并发依据工具的 `concurrency_safe` 属性，不是任务图。

`spawn` 工具位于 `nanobot/agent/tools/spawn.py`：

- 是否调用完全由父模型决定；
- 输入是自由文本 `task`、可选标签、温度和 `wait`；
- 并发上限只在调用时检查，默认配置为 1。

`nanobot/agent/subagent.py` 中的子 agent：

- 使用独立的工具注册表和通用执行者提示词；
- 只接收系统提示词与父 agent 提供的 `task` 文本；
- 不继承父会话历史、任务帧或任务图；
- 完成后以内部消息回注父会话，结果可按字符预算持久化为引用。

## 5. 当前改动与本主题的关系

当前工作区存在未提交的 subagent 生命周期、结果预算和 WebUI 展示相关改动。它们改善了已派发 subagent 的观察与回传，但不引入任务锚定、自然语言意图状态或委派前置门。

特别注意：`nanobot/templates/agent/tool_contract.md` 目前要求“状态不确定时先只读发现”。在本主题确认的规则下，这句话只能适用于“对象已锚定但对象状态未知”的情况；对象不存在或指代不明时，不得以此调用发现工具。

## 6. 设计约束

- `AgentLoop` 与 `AgentRunner` 是核心路径，项目约束要求变更最小且有明确理由；
- 新能力优先使用既有工具、技能、运行时上下文与会话模式；但前置任务准入是跨工具安全门，不能仅靠提示词模拟；
- 工具具有文件、Shell、网络和外部副作用能力，因此对象锚定不能等同于操作授权；
- 当前源码树含用户未提交改动，后续实现必须从隔离开发分支开始，并在实现前复核基线。

## 7. 后续取证清单

- 在架构方案阶段，核对 `AgentLoop` 可插入的最小前置扩展点；
- 设计任务状态持久化前，核对 session metadata、历史压缩与 Dream 的兼容性；
- 设计 subagent 并行前，核对工作区范围、写入隔离、取消和 WebUI 生命周期；
- 建立对话回放集后，以真实调用轨迹验证“无对象零工具调用”和“多候选必澄清”。
